# Sales & Revenue Dashboard (Power BI)

### Objective
Analyze company sales data to identify key trends, high-performing products, and profit growth opportunities.

### Tools Used
- Power BI
- Excel

### Key Insights
- Total sales: ₹10.2M across 4 regions.
- South region had highest revenue (32% share).
- Introduced Year-to-Date (YTD) and Month-over-Month (MoM) analysis using DAX.

### Outcome
Enhanced management reporting and reduced manual report preparation time by 40%.
